# 評分準則 Judging Criteria

**決賽（C2:Q3:I5）**

## 創意（C）
- 作品是否全新及重要？  
  *Is the work novel and significant?*
- 是否與眾不同？  
  *Is it distinctive?*
- 能否解決更廣泛的全球議題？  
  *Can it address broader global issues?*

## 素質（Q）
- 作品是否以具邏輯方式針對問題並提出方案？  
  *Does the work effectively solve the problem with a well-reasoned solution?*
- 有關項目是否在設計思維的框架下作出測試及改善？  
  *Has the project undergone rigorous testing and iteration within a design thinking framework?*

## 影響（I）
- 項目是否與目標受惠社群有緊密關系？  
  *Is the project deeply connected to its target beneficiary community?*
- 有否得到受眾的正面回應？  
  *Has it received positive feedback from the target audience?*
- 是否具備可延展能力至其他領域？  
  *Does it demonstrate potential for broader scalability?*
